# 🏠 HOUSE PRICE PREDICTION WEBSITE

A Machine Learning-based web application that predicts house prices using property details such as area, city, bedrooms, bathrooms, and amenities.

The system provides accurate house price estimation through predictive analytics and includes user authentication, dashboards, analytics, and market insights.

## 📖 Project Overview

House price prediction is an important real-world application of Machine Learning in the real estate industry.

This project helps users estimate house prices by analyzing multiple property-related features and generating accurate predictions.

The application also provides:

- User authentication
- Admin dashboard
- Prediction history
- Market insights
- User analytics
- Data visualization

---

## ❗ Problem Statement

Estimating house prices manually is complex because property prices depend on multiple dynamic factors such as location, amenities, area, and market trends.

Traditional estimation methods can be inconsistent and time-consuming.

This project solves the problem by providing an automated machine learning-based prediction system.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/shaiksharif1234/HOUSE_PRICE_PREDICTION.git
```

### Move to Project Folder

```bash
cd HOUSE_PRICE_PREDICTION
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```
